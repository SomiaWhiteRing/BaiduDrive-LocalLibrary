# 中文写作规则

本项目使用自定义的中文受控写法。

写法借鉴 [ASD-STE100](https://www.asd-ste100.org/faq.html) 的规则和受控词汇思路，并按中文表达习惯制定具体规则。

## 规则

1. 一个句子表达一个动作或事实。
2. 一个步骤要求一个主要动作。
3. 先写条件，再写动作。
4. 使用主动句。
5. 使用同一个术语表示同一个对象。
6. 操作句以明确动词开始。
7. 在操作前说明必要条件。
8. 在操作后说明可观察的结果。
9. 将风险说明放在相关操作之前。
10. 使用参数名、路径和状态字段消除歧义。

操作句的中文正文以 40 字以内为目标。代码、路径和标识符按原文完整保留。

## 固定术语

| 术语 | 含义 |
| --- | --- |
| 文件库 | Windows 中呈现的文件目录 |
| 运行目录 | 配置、凭据和运行状态所在目录 |
| 仓库 | 本项目的源代码目录 |
| 本地入口 | 绑定本机端口的 HTTP 入口 |
| 适配器 | WebDAV 格式转换服务 |
| 标记文件 | 表示已登记空文件的远端内容 |
| 配对 | 客户端首次保存本地账号的操作 |
| 启动 | 复用现有配置运行服务和客户端 |
| 本地凭据 | 用于本地 Nextcloud 账号校验的凭据 |
| 百度授权 | OpenList 访问百度所需的授权 |

## 操作示例

> 如果本地密码已更改，执行 `SaveCredential`。
> 再执行 `Start`。
> 确认 `client_running` 为 `true`。

## 文档检查

提交文档前，检查以下内容：

- 命令与实际入口一致。
- 参数和状态字段拼写一致。
- 条件、动作和预期结果相互对应。
- “已验证”说明包含检查范围。
- 路径和凭据示例使用通用占位值。
