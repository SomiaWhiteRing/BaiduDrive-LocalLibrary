# 架构边界

## 组件职责

| 组件 | 职责 | 状态管理 |
| --- | --- | --- |
| Windows 入口 | 初始化、启动、停止、自启和本地账号校验 | 实例记录、DPAPI 凭据、启动日志 |
| Nextcloud 客户端 | Windows Cloud Files 占位符和同步 | 专用配置、同步数据库、系统凭据 |
| 本地入口 | 将本机 HTTP 请求转发到内部网络 | 配置文件 |
| Nextcloud | 提供账号、文件接口和外部存储 | 配置、数据目录、数据库 |
| 后台任务 | 执行 Nextcloud 定期任务 | 使用相同配置和数据库 |
| 适配器 | 空文件、逻辑修改时间和写入恢复 | 适配器状态目录 |
| OpenList | 百度授权和存储驱动 | 存储配置和授权 |
| MariaDB | Nextcloud 元数据 | 数据库目录 |
| Redis | 临时锁和缓存 | 重启时重建的内存缓存 |

## 空文件协议

百度端保存非空标记文件。标记包含格式名、随机值和空内容摘要。

已登记的标记按空文件协议转换。其余内容保持原样。

每个 WebDAV 用户使用独立的空文件登记。

适配器在读回时核对完整标记。标记在适配器之外被更改时，适配器报告错误。

客户端和 Nextcloud 看到的空文件大小为零。

## 写入和恢复

适配器先完整接收上传内容，再写入上游。

普通文件按原始字节传递。空文件内容转换为标记文件。

适配器先登记待完成写入，再提交已确认结果。

如果操作中断，恢复记录会保留。适配器在远端结果确认后提交成功状态。

复制、移动和删除操作会同步更新标记登记。命名空间操作确认完成后，相关路径恢复变更。

## 状态目录

`DATA_DIR/empty-codec` 包含以下状态：

- `empty-files.sqlite`：空文件、待完成写入、命名空间操作和修改时间。
- `initialized-v1`：初始化哨兵。
- `temporary`：上传中的临时内容。

适配器启动时核对数据库与哨兵。状态校验通过后，服务开始运行。

启动提示恢复数据库时，先恢复成套状态，再启动服务。

停止服务后，备份整个运行目录，完整保存数据库和哨兵。

## 启动边界

`Start` 复用已配对的本地账号。

它检查服务器地址、账号名、本地目录、远端目录和虚拟文件模式。

工具可以关闭默认客户端的空实例。默认客户端已有账号时，先自行退出该实例，再启动本项目。

首次配对由显式的 `Pair` 操作触发。
