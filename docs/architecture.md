# 架构边界

## 组件职责

| 组件 | 职责 | 持久状态 |
| --- | --- | --- |
| Windows 入口 | 初始化、启动、停止、自启和本地账号校验 | 实例记录、DPAPI 凭据、启动日志 |
| Nextcloud 客户端 | Windows Cloud Files 占位符和同步 | 专用配置、同步数据库、系统凭据 |
| 本地入口 | 将本机 HTTP 请求转发到内部网络 | 无用户数据 |
| Nextcloud | 提供账号、文件接口和外部存储 | 配置、数据目录、数据库 |
| 后台任务 | 执行 Nextcloud 定期任务 | 使用相同配置和数据库 |
| 适配器 | 空文件、逻辑修改时间和写入恢复 | 适配器状态目录 |
| OpenList | 百度授权和存储驱动 | 存储配置和授权 |
| MariaDB | Nextcloud 元数据 | 数据库目录 |
| Redis | 临时锁和缓存 | 无持久快照 |

## 空文件协议

百度端保存非空标记文件。标记包含格式名、随机值和空内容摘要。

适配器只转换自己已登记的标记。普通文件即使具有相同前缀，也不自动变为空文件。

登记信息按 WebDAV 用户隔离。不同用户名不能共用同一份空文件登记。

适配器在读回时核对完整标记。标记在适配器之外被更改时，适配器报告错误。

客户端和 Nextcloud 看到的空文件大小为零。

## 写入和恢复

适配器先完整接收上传内容，再写入上游。

普通文件内容不做格式转换。空文件内容转换为标记文件。

适配器先登记待完成写入，再提交已确认结果。

如果操作中断，恢复记录会保留。适配器不会把不明确的远端结果当作成功。

复制、移动和删除操作会同步更新标记登记。未确认的命名空间操作会阻止相关路径继续变更。

## 状态目录

`DATA_DIR/empty-codec` 包含以下状态：

- `empty-files.sqlite`：空文件、待完成写入、命名空间操作和修改时间。
- `initialized-v1`：初始化哨兵。
- `temporary`：未完成上传的临时内容。

如果哨兵存在而数据库缺失，适配器拒绝启动。

停止服务后，备份整个运行目录。不要只复制 SQLite 文件，也不要单独删除哨兵。

## 启动边界

`Start` 只复用已配对的本地账号。

它检查服务器地址、账号名、本地目录、远端目录和虚拟文件模式。

默认客户端没有账号时，工具可以关闭该空实例。默认客户端已有账号时，工具保留该实例并报告错误。

首次配对只由显式的 `Pair` 操作触发。

## 提取边界

本项目没有包含以下内容：

- OneDrive 清单、下载、迁移或缓存释放逻辑。
- 个人文件名例外和目录修复脚本。
- 生产凭据、设备标识和运行数据库。
- 原有桌面界面、图标和第三方二进制文件。

核心代码只依赖本仓库配置和外部组件的公开接口。
