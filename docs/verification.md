## 2026-10-25 挂载不可用修复

原版本在文件待完成写入时，将父目录元数据也返回为 HTTP 503。
Nextcloud 会据此暂时将整个外部存储标记为不可用。
修复后，受影响路径返回 HTTP 423，父目录自身的元数据继续返回 HTTP 207。

临时检查已覆盖本机和另一台适配器观察到的待完成操作：

- 父目录元数据和无关文件继续可读。
- 包含受影响条目的目录列表返回锁定状态。
- 重叠的移动操作等待原操作完成。
- 操作完成后，受影响路径恢复可读。
- 现机 Nextcloud 将 423 转换为路径锁定，将 503 转换为存储不可用。

状态检查增加实际文件库的 `PROPFIND` 探测。
`file_accessible` 为真时，文件接口已通过认证并返回 HTTP 207。
`ready` 同时要求服务器、客户端、共享元数据和文件接口就绪。
