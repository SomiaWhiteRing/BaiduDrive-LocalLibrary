# 故障处理

## 全局排除规则权限

安装器可能将 `sync-exclude.lst` 的所有者设为 SYSTEM。
普通用户通常只有读取权限。

执行 `ApplyPolicy`。工具按需请求 Windows 管理员确认，并授予当前用户该规则文件的修改权限。
原文件所有者和其他权限继续保留。

## 共享元数据尚未就绪

1. 确认两台设备连接相同的百度物理目录。
2. 在已有设备执行 `PublishMetadata`。
3. 在新设备执行 `RefreshMetadata`。
4. 如果提示待完成写入，在原设备恢复服务并重试该操作。

具体格式和故障边界见[多设备元数据](multi-device.md)。

先执行 `Status`。再检查运行目录中的 `logs/startup.log`。

| 现象 | 检查项 | 处理 |
| --- | --- | --- |
| 提示缺少配置 | `.env` 是否存在 | 复制示例并修改字段 |
| 初始化提示选择空目录 | 运行目录是否属于其他实例 | 选择新的空运行目录 |
| 提示镜像缺失 | 是否执行过 `Prepare` | 在维护时执行 `Prepare` |
| 本地入口连接超时或返回连接错误 | Docker 和容器是否运行 | 检查 Docker Desktop 与容器日志 |
| 外部存储不可用 | OpenList 用户和 `/baidu` 挂载 | 在 OpenList 中验证读写 |
| 本地校验返回 401 | 本地账号凭据是否失效 | 执行 `SaveCredential` |
| 本地校验返回 404 | 外部存储名是否匹配远端路径 | 检查 `CLIENT_REMOTE_PATH` |
| 提示执行客户端配对 | 专用配置中的账号记录 | 显式执行 `Pair` |
| 提示检查本地账号地址 | 客户端是否连接到其他服务器 | 按本地入口地址检查专用配置，保留其他账号 |
| 默认客户端已有账号 | 是否运行了其他配置 | 自行退出该实例，再启动本项目 |
| 文件列表与上游目录存在差异 | 上游客户端的排除规则 | 检查相关文件名是否匹配规则 |
| 空文件读取返回 409 | 百度端标记是否被直接修改 | 保留状态，检查已知备份 |
| 启动提示恢复状态数据库 | 数据库与哨兵是否成套 | 恢复同一时间点的完整运行目录 |
| 重命名后提示核对操作结果 | 命名空间操作的确认状态 | 保留状态，核对上游操作结果 |

## 容器日志

在仓库根目录执行：

```powershell
docker compose --env-file .env logs --tail 100 nextcloud nextcloud-gateway empty-codec openlist
```

日志可能包含路径或账户信息。发布日志前，删除个人信息和凭据。

公开问题附上脱敏后的日志片段和配置字段。完整运行资料保存在私有环境中。

## 恢复操作原则

- 保留空文件登记，并按校验结果处理冲突。
- 保持本机监听地址，并检查本地网络链路。
- 保留运行目录，使用同一时间点的完整备份恢复。
- 等待传输结束，再正常退出客户端。

恢复操作前，先核对状态。需要进一步调查时，暂停变更并保留现场。
